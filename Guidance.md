Design and implement an LLM-based application that uses training-free strategies to address a
practical problem in a scenario chosen by your group. The outcome should be a working system
that a user can interact with.
The application must show that you understand at least one modern LLM technique. These
include, but are not limited to:
• Retrieval-Augmented Generation (RAG);
• Model Context Protocol (MCP);
• Agent Skills.
You are encouraged to use an external knowledge source, such as a document collection, a database, or a knowledge graph, when it fits the application. You do not need to run a large comparative experiment. You do need to explain why the design is appropriate and why the system behaves correctly.
