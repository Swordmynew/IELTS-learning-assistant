代码位于 `upstream/personal-learning-coach`，基于 `feature/personal-learning-coach` 的 `1b9d3d1`，这是实现时的来源基线；当前交付仓库和默认分支见 [START_HERE](../START_HERE.md)。

## 已完成

1. **碎片笔记**：个人知识库支持新建、编辑、删除文本笔记，填写科目、知识点、可选来源链接，并关联已有学习记录。明确清空的标签不会被自动恢复。
2. **原文收藏**：从题目、作文和通用答疑收藏片段。后端按所有者校验来源，摘录必须原样存在；保存原文快照、来源定位和来源类型。API 也支持从已摄入文档收藏片段并保留已有页码。
3. **错误事件与知识点**：为实际错误和后续作答保存独立事件；按知识点关联同类记录，统计不同作答事件，重复回填不重复计数。词义测试和题目历史事件可回填。首次事件原文保留，知识条目可继续更新。
4. **个性化检索**：保留向量/关键词融合，增加知识点与关联记录召回；使用错误次数和待复习/已改善状态小幅调节排序。权限和显式来源/知识点筛选先行；相关性仍是主要依据。
5. **检索预览**：个人知识库的“查找相关资料”不需要模型密钥。返回当前匹配片段及原因，可检查个人笔记是否确实进入检索。
6. **复习闭环**：客观题新作答、作文复评会更新个人记忆；另提供手工复习记录，明确标为自评。自评不增加客观练习或错误次数，一次答对不宣称已掌握。
7. **记忆生命周期**：编辑、删除、合并和新事件使当前用户模型缓存失效。受影响的旧回答标记为依据过时，不再进入后续模型历史。生成期间记忆变化会拒绝旧模型结果并重新检索来源。其他用户的资料与缓存不受影响。
8. **来源区分**：手工笔记、练习摘录、作文原文、AI 答疑摘录保留不同来源标记。模型提示明确将资料作为数据，并区分学习记录与权威依据；不把收藏的 AI 回答当作独立证明。

知识点自动建议采用可解释的关键词规则与已有科目/评分项，用户可修改；目前没有将其宣称为经人工验证的自动错误分类器。

## 数据与接口

复用现有 `coach_records` 表，新增 payload 内容和 `knowledge_event`、`memory_revision` 记录类型；未新增表或修改列，因此本分支迁移仍为 `0007_personal_coach`。这不代表可直接兼容旧目录的 `0012_model_calls` 数据库。

| 接口（均在 /api/v1 下） | 用途 |
| --- | --- |
| POST /knowledge/items | 新建手工笔记；request_id 支持相同请求重试 |
| GET /knowledge/items | 查看个人条目、标签和练习/错误统计 |
| PATCH /knowledge/items/{id} | 修改备注/标签/关联，手工笔记还可修改内容与链接 |
| POST /knowledge/bookmarks | 校验并收藏 question / writing_version / conversation / document 摘录 |
| GET /knowledge/topics | 预设知识点与本用户主题聚合 |
| GET /knowledge/items/{id}/events | 查看本用户原始事件及合并后的来源事件 |
| POST /knowledge/items/{id}/reviews | 保存明确标记的复习自评；request_id 防重复 |
| POST /rag/preview | 只检索，不调用生成模型 |
| POST /rag/query | 带 source_type、document_ids、topic_tags 的问答 |

已有知识编辑/删除/合并接口与作文提词等功能保留。来源原文快照不可通过“编辑笔记内容”覆盖；用户自己的备注可独立修改。收藏重复原文返回已有条目；不同内容复用同一请求标识返回冲突，避免静默覆盖。

主实现：`backend/app/services/learning_memory.py`、`backend/app/memory_api.py`、`backend/app/services/search_repository.py`；界面：`frontend/app/resources/knowledge-editor.tsx`、`personal-knowledge.tsx`，并接入题库、写作及悬浮助手。

## 本地体验

1. 打开 http://127.0.0.1:3000/resources ，未登录时进入演示空间或注册本地账号。
2. 选择“新建笔记”，输入自己的文字与知识点，例如“不可数名词”。
3. 展开“查找相关资料”，用相关问题查找，打开来源查看实际片段。
4. 在题库或写作工作台点击“收藏”，可先选中一段原文；保存后回个人知识库查看。
5. 点击“记录复习”，选择本次自评并保存；展开“学习记录”核对来源与状态。

预览继续使用现有 Conda `ielts-coach`、`PYTHONNOUSERSITE=1`、独立 SQLite 数据库、离线模型和哈希向量。没有新建 venv/uv，也未修改 ai-dev/CUDA。启动脚本：`scripts/start-conda-preview.ps1`；端口正在使用时直接打开页面。
