# 演示操作单（中文，不投屏）

## 使用方式

PPT第1–17页共15分钟，第18页另留4分钟问答。按[六人分工](PRESENTATION_PLAN_ZH.md)主讲，E唯一操作。第6–11页由C/D说明操作与结果，E配合切页；第12–15页是E的4分钟集中演示。全流程时间已含在15分钟里。

图片可在放映时点击，打开http://127.0.0.1:3000对应页面。需要先启动服务并在普通浏览器登录；PPT不会自动登录截图账号，也不会把截图数据导入当前账号。当前系统界面为中文，PPT截图使用英文展示译注。截图状态来自合成账号Alex，不是用户实验数据。

## 上场前

- 使用项目启动器预热本地前端3000、后端8000，提前打开概览、档案、计划、题库、知识库和写作页面。
- 使用隔离演示库、合成账号；目标输入5.5→7.0，考试日设在未来30天，每日90分钟。630分钟是周容量，计划示例实际安排320分钟，不承诺30天提分。
- 准备手动笔记“However: contrast, not cause”，正文“Use however for a genuine contrast. Use for example to introduce supporting evidence.”；已有就复用。
- 准备原创文本型两页PDF，第二页包含“Page 2: use for example to introduce supporting evidence.”，不上传私人或未授权文件。
- 当前预览是offline/hashing；写作V1/V2来自固定原创离线示例。它不是基于Alex新增笔记现场生成的评价。

## 第6–11页配合操作

| 页 | 页面与动作 | 核对结果 |
| --- | --- | --- |
| 6 | 题库展开阅读题，第一题故意选择True提交 | 参考False和解析；这是项目原创模拟题 |
| 7 | 个人知识库查看错误，再添加上述片段笔记；范围切到全部 | 错误事件和手动笔记是两种独立记录 |
| 8 | 检索“however supporting evidence”，展开对应笔记 | 实际命中有多条，示例笔记是第2条，不声称排第1 |
| 9 | 上传或打开预置PDF，选第2页 | 原文与页码可核对；可打开受鉴权保护的原文件 |
| 10 | 计划页生成草案 | 显示草案状态，示例10项任务共320分钟 |
| 11 | 明确批准，再标记一项完成 | 草案成为启用计划；概览10%是1/10项完成率，不是正确率 |

实际新建账号的顺序和数量可能变化；解释真实页面，不能强行将不同输出说成与截图完全一致。

## 故障回退

- 浏览器或服务故障：直接用本PPT对应实际截图讲解，明确是预先捕获状态；不假装现场成功。
- 草案冲突：保留真实报错，切可行档案或第10–11页截图，不强行批准。
- 检索未命中：检查范围、资料状态、笔记词项；切第8页示例，不捏造来源。
- 模型不可用：第15页已保留真实离线返回；写作使用固定示例。真实模型能力需另做验收。
- 单步超过10秒未恢复：切截图，继续原定时间。截图详见[来源清单](assets/demo/README.md)。
