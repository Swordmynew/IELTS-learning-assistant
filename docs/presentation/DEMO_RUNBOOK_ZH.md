# 四分钟课堂演示操作单

只由成员E操作。PPT第9页讲解/切屏3分钟，第10页1分钟，共4分钟；系统UI当前是中文，PPT展示页为英文。不要现场更改系统语言或边讲边首次安装依赖。

## 上场前

- 从当前项目启动隔离预览；打开所有目标页面，避免现场首次编译。使用演示账号及合成资料。
- 考试日期设在未来，时间足够生成可批准草案。不要用过期日期、时间不足或已有冲突状态作为成功案例。
- 预置“演示：information 的数量表达”：many information → much information / a piece of information，标签“不可数名词”。已有该笔记就复用。
- 公共“Task 2 · 论证展开”可用于原文收藏；PDF原文可预先上传合成文本型PDF，不能现场上传私人文件。
- 当前预览启动器强制离线/hashing。真实模型模式需另行配置、重启并预演；绝不能把固定示例当成对现场作文的实时反馈。

## 逐秒操作

| 演示时间 | 页面与动作 | 应看到的证据 | 口头说明重点 |
| --- | --- | --- | --- |
| 00:00–00:15 | 学习概览，指出目标和当前记录 | 演示账号与目标 | 使用同一账号贯穿流程 |
| 00:15–00:30 | 档案查看考试日、时间、目标 | 未来日期与每日分钟 | 计划受用户约束 |
| 00:30–01:10 | 本周计划生成、核对并启用 | 实际节点进度、草案、已启用 | 用户审批才成为正式计划；若已有计划可重新生成 |
| 01:10–01:30 | 背单词开始学习，翻卡并记录结果 | 释义与队列前进 | 翻卡不需要生成模型 |
| 01:30–02:00 | 展开阅读题组，故意提交第一题错误答案 | 参考False、解析、待复习 | 明确说是故意答错的合成演示 |
| 02:00–02:45 | 个人知识库查看新增错误；检索information并展开 | 错误事件、个人笔记、原文与匹配原因 | 当前请求能利用个人积累；检索预览不调用生成 |
| 02:45–03:05 | 查看来源片段或预置PDF页码，收藏并保留备注 | 原文、页码/来源与已收藏 | 原句与个人备注分开 |
| 03:05–03:40 | 写作工作台打开离线示例V1、方向提示、V2 | 固定示例标识和问题改善对照 | 这是原创示例，不是新作文的真实评分 |
| 03:40–04:00 | 个人助手选“怎样展开Task 2论据”，查看来源 | 来源列表和明确离线状态 | 实时生成不可用时系统仍可显示检索证据 |

题目库只有项目原创模拟内容，不能讲成官方真题。若该题此前已作答，仍能再次提交，但不要把累积次数当新用户实验。

## 回退

- 草案冲突：不强行批准，改用预先验证的可行档案；时间紧时展示草案截图并说明冲突。
- 来源未命中：先查看资料状态、范围和词项，展示预置information笔记；不临时捏造来源。
- 模型不可用：展示检索证据/固定示例与实际模式；不说“刚刚AI生成”。
- 浏览器或服务故障：切回PPT，用仓库docs/assets已有合成截图解释操作结果；若使用预录视频，必须标为预录且只显示已记录能力。
- 单步超过10秒未恢复：停止现场排查，口头说明后切备份，保护其他成员时间。
