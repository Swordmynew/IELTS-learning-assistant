本目录23张PNG来自当前项目本地页面的实际操作，使用隔离演示库与合成账号Alex。没有真实用户信息、真实模型调用或人工评分数据。截图不是设计稿。

## 英文展示译注

实际产品界面为中文。捕获脚本仅在截图期间翻译可见DOM文字和选项标签，之后恢复；未修改应用语言功能或伪造后端结果。英文译注供课堂投屏，并不代表产品完成英文国际化。完整记录见[MANIFEST.json](MANIFEST.json)，每项包含路由、翻译计数与未翻译项检查。

## 数据解释

- 画像5.5→7.0、30天后考试、每日90分钟仅为输入，不是提分承诺。
- 完成率10%是10项任务中的1项，不是准确率或效果评估。
- 错题来自项目原创题目的故意错误提交，手动片段是独立记录。
- 检索示例笔记实际为第2条；PDF第2页来自原创合成文件。
- 写作V1/V2是固定原创离线示例，不是根据Alex笔记即时生成的评分。
- 助手画面保留真实的模型不可用状态和检索来源，没有补写模型回答。

## 复现入口

项目根目录scripts/presentation/capture-demo.mjs负责UI操作与捕获，ui-translation.json保存展示译文，build.mjs负责组装PPT。捕获需要本地3000/8000服务及已有Playwright依赖，运行会在当前演示库创建合成账号与记录；请使用隔离预览库。临时清单及构建预览留在已忽略的local-data目录，不应上传实际数据库或凭据。

PPT截图附有本地页面链接；链接不会导入演示账号状态。演示者应提前登录自己的合成账号，若无法启动服务，直接用截图说明预先捕获结果。
