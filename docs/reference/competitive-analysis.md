# 雅思学习平台公开功能调研与产品决策

调研日期：2026-09-04

## 调研范围

本次仅参考公开产品页的信息架构和功能描述，不登录付费服务、不复制界面，也不获取或重新分发商业题库。

- [新东方在线雅思智能学习平台](https://ielts.koolearn.com/zhuanti/zxys/)：公开页面展示入学测评、四科单独设定目标分数、按目标生成学习路径、根据表现补充课表、每日进度和能力变化。
- [新东方在线雅思课程与练习](https://www.koolearn.com/ke/ielts/)：公开页面展示按顺序、题型和场景练习，精听训练、口语写作范例及正版题库等能力。
- [新航道在线](https://hibook.xhd.cn/)：公开首页将产品划分为录播课、雅思在线机考、听说读写题库和备考资料。
- [新航道鲸准英语智能测评系统说明](https://www.xhd.cn/news/94002428.html)：公开说明列出个人资料、密码修改、题库、组卷、测试记录和课程表等分区。

## 对本项目的判断

商业平台的核心优势包含正版内容、教师服务和完整课程，这些并不是作品集 MVP 应该虚构的能力。当前项目更适合突出可审计的 AI 工程闭环：

`学习档案 → 自适应计划 → 套题/专项练习 → 服务端批改 → 错题复习 → 能力画像与后续计划`

## 本轮采用

1. 学习档案的四科当前分数、目标分数和可用时间使用明确的数据绑定。
2. 首页增加四阶段备考路径，集中展示下一步，而不是堆叠全部功能。
3. 题库增加“全部练习 / 错题复习”、科目筛选、题型筛选和练习统计。
4. 阅读使用桌面端文章与题目双栏布局；小屏自动切换单栏。
5. 听力加入速度选择、播放和练习后查看原文；浏览器合成语音继续明确标记为演示。
6. 客观题答案不再随题目列表返回浏览器；用户提交后由后端判分，再返回答案与解析。
7. 参考公开个人中心的“基本资料、学习记录、账号安全”分区，新增独立登录/注册、用户中心和设置页；不引入与自学产品无关的订单、优惠券和教师管理。
8. 参考在线机考的阅读工作区，将文章和题目设为等高双栏并分别滚动；答题选项默认使用紧凑密度，同时允许用户在设置中切换。
9. 每题最近一次作答决定是否进入错题复习，答对后自动移出。

## 暂不实现

- 新东方等平台所拥有的正版剑桥题库：项目没有相应授权。
- 真人教师精批、直播答疑、1 对 1 口语模考：需要教师运营体系，不能用静态页面冒充。
- 完整官方机考复刻：需要更多题型组件、计时、答题卡、音频素材及端到端测评，本阶段只完成可验证的练习闭环。
- “当季预测”“命中率”等宣传功能：缺少可靠数据来源和可验证方法。

## 后续优先级

1. 增加完整套题会话、倒计时、答题卡和交卷报告。
2. 将阅读/听力错题标签回写 `SkillProfile`，让下一周计划自动提高对应题型优先级。
3. 支持授权音频上传、分段时间戳、单句循环和听写模式。
4. 增加分题型正确率趋势与学习时长趋势，而不是只显示累计数字。
